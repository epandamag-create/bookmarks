# Cyberpunk Theme for Bookmark OS

## Обзор

Тема **Cyberpunk Neon** — это футуристический дизайн в стиле киберпанк с неоновыми акцентами, тёмным фоном и эффектами свечения.

## Характеристики

### Цветовая палитра
- **Основной акцент**: Неоновый розовый (`#ff00ff`)
- **Вторичный акцент**: Неоновый циан (`#00ffff`)
- **Фон**: Глубокий чёрный с оттенками фиолетового (`#05050a`)
- **Текст**: Белый с мягким свечением
- **Успех**: Ярко-зелёный (`#00ff9d`)
- **Предупреждение**: Золотой (`#ffcc00`)
- **Ошибка**: Малиновый (`#ff2a6d`)

### Визуальные эффекты
- **Glow effects**: Все интерактивные элементы имеют неоновое свечение
- **Text shadows**: Текст с лёгким свечением для лучшей читаемости
- **Gradient backgrounds**: Градиенты для глубины и объёма
- **Box shadows**: Тени с цветными оттенками для создания атмосферы
- **Drop shadows**: Иконки с цветными тенями

### Компоненты

#### Sidebar
- Градиентный фон от тёмно-фиолетового к чёрному
- Неоновая полоска слева при наведении на пункты меню
- Логотип с градиентом розовый→циан и свечением
- Активные элементы с внутренним свечением

#### Topbar
- Полупрозрачный фон с размытием
- Розовое свечение снизу
- Поле поиска с неоновой подсветкой при фокусе

#### Карточки закладок
- При наведении: подъём + свечение
- Теги с неоновым свечением
- Избранные звёзды с золотым свечением

#### Таблицы
- Строки с подсветкой при наведении
- Сортируемые колонки с неоновым текстом
- Выделенные строки с розовым фоном

#### Модальные окна
- Сильное внешнее свечение
- Градиентные границы
- Поля ввода с неоновой подсветкой при фокусе

#### Кнопки
- Primary: розовый фон с ярким свечением
- Ghost: прозрачные с подсветкой при наведении
- Danger: малиновые с красным свечением

## Установка

Тема автоматически интегрирована в приложение и доступна через переключатель тем в настройках.

### Переключение тем
1. Откройте **Settings** (Настройки)
2. В секции **Appearance** найдите кнопку **Switch Theme**
3. Нажимайте для циклического переключения: Default → Black → Cyberpunk → Default...

### Сохранение темы
Выбранная тема сохраняется в `localStorage` под ключом `bm_theme` и восстанавливается при следующей загрузке страницы.

## Совместимость с цветовыми схемами

Тема полностью совместима с системой цветовых схем Bookmark OS. Вы можете изменить основной цвет акцента через настройки, и тема адаптируется:

- Изменение `--scheme-accent` повлияет на все неоновые эффекты
- Вторичный акцент (циан) остаётся неизменным для сохранения стиля
- Все цвета свечения пересчитываются автоматически

## Технические детали

### CSS переменные
Тема использует стандартные переменные Bookmark OS:
```css
--scheme-accent
--scheme-accent-hover
--scheme-accent-bg
--scheme-accent-border
--scheme-accent-glow
```

И добавляет уникальные:
```css
--accent-secondary: #00ffff
--accent-secondary-bg: rgba(0,255,255,0.1)
--accent-secondary-glow: rgba(0,255,255,0.5)
```

### Файлы
- `styles cyberpunk.css` — основные стили темы
- `app.js` — обновлённый переключатель тем (добавлена тема Cyberpunk)
- `index.html` — обновлённый список допустимых тем

## Производительность

Тема оптимизирована для производительности:
- CSS анимации используют `transform` и `opacity` (аппаратное ускорение)
- Эффекты свечения реализованы через `box-shadow` и `text-shadow`
- Backdrop-filter используется умеренно для совместимости

Сравнение
Плюсы и минусы каждого варианта

A — Current

Glassmorphism с полоской сверху. Хорошо вписывается в существующий стиль без изменений.

Не нужно менять CSS Средняя плотность Полоска сверху занимает место

B — Compact Row

Горизонтальная строка. Максимум карточек в одной колонке. Похоже на List view в Dashboard.

Высокая плотность Нет описания — меньше шума Нет места для описания

C — Media Card

Цветная обложка сверху с фавиконом. Самый богатый визуально. Хорош когда карточек мало.

Выразительный Хорошо передаёт цвет категории Низкая плотность

D — Glassmorphism Pill

Фавикон + домен слева, свечение цветом категории. Современный и мягкий.

Современный вид Крупный фавикон Требует backdrop-filter

E — Left Stripe

Вертикальная полоска слева. Компактнее текущего, не теряет цветовую идентификацию.

Компактный Минимальные правки CSS Менее заметен цвет

F — Notion Flat

Максимально плоский. Кнопки скрыты до hover. Самый тихий визуально.

Чистейший вид Много карточек в колонке Кнопки не видны Слабо выражен цвет

G — Split Panel

Верхняя часть с фавиконом и текстом, нижняя — мета. Разделитель создаёт чёткую структуру.

Чёткая иерархия Крупная иконка Чуть выше текущего

H — Neon Glow

Цвет категории проникает в рамку, фавикон и домен. Hover даёт glow-эффект.

Уникальная атмосфера Цвет повсюду Может быть ярко Требует color-mix()

I — Timeline

Карточки соединены линией как в activity feed. Нестандартный подход для Dashboard.

Очень компактный Хорош для Starred/Recent Непривычно для Dashboard

J — Stat Card

Визиты — главный показатель. Прогресс-бар показывает активность. Аналитический подход.

Информативный Уникальный в своём классе Прогресс-бар требует max

K — Tag-first

Категория вынесена как лейбл наверх. Теги покрашены в цвет категории. Подчёркивает контекст.

Контекст сразу виден Теги выразительны Дублирует колонку категории

L — Mini Square

Квадратная плитка. Как app grid на мобильном. Хорош при большом числе колонок.

Очень компактный Крупный фавикон Нет места для описания

M — Gradient Border

Рамка как градиент. Тёмный фон внутри. Элегантно, не перегружено.

Нарядный вид Не требует backdrop-filter Плохо работает без --cc

N — Sticky Note

Загнутый уголок, подкрашенный фон — как физический стикер. Уютная, «тёплая» эстетика.

Запоминается Цвет категории мягко виден Нестандартный вид

O — Wide Row

Широкая горизонтальная карточка на всю ширину. Полоска + фавикон слева, мета справа.

Идеален для 2-3 колонок Много информации Слишком широк для 4-5 колонок

P — Minimal Mono

Полностью моноспейсный. Теги через #. Терминальная эстетика для разработчиков.

Максимально тихий Отличная плотность Нет фавикона Нишевая эстетика

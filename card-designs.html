Сравнение
Плюсы и минусы каждого варианта

A — Current

Glassmorphism с полоской сверху. Хорошо вписывается в существующий стиль без изменений.

Не нужно менять CSS Средняя плотность Полоска сверху занимает место

B — Compact Row

Горизонтальная строка. Максимум карточек в одной колонке. Похоже на List view в Dashboard.

Высокая плотность Нет описания — меньше шума Нет места для описания

C — Media Card

Цветная обложка сверху с фавиконом. Самый богатый визуально. Хорош когда карточек мало.

Выразительный Хорошо передаёт цвет категории Низкая плотность

D — Glassmorphism Pill

Фавикон + домен слева, свечение цветом категории. Современный и мягкий.

Современный вид Крупный фавикон Требует backdrop-filter

E — Left Stripe

Вертикальная полоска слева. Компактнее текущего, не теряет цветовую идентификацию.

Компактный Минимальные правки CSS Менее заметен цвет

F — Notion Flat

Максимально плоский. Кнопки скрыты до hover. Самый тихий визуально.

Чистейший вид Много карточек в колонке Кнопки не видны Слабо выражен цвет
